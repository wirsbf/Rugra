# 开发工作流红线规范 (Workflow Template)

本目录建立用于处理日常非文档层面上手操作的具体指导工作流和必经查验清单。每次在处理不同的议题时（修复问题 vs 添加新模型），参照指定流。

## 约定格式

### 1. 工作流类型声明 (Workflow Context)
明确本清单适用于哪些场景，如 `[Bug-Fix]`, `[Alignment-Sync]`, `[Feature-Addition]` 等。

### 2. 本地执行命令流 (Steps & Commands)
列出能够直接拷贝的各种 `cargo`、格式化或者专门的对比跑测工具代码以防止因流程缺乏而导致的质量退化。

### 3. 操作禁区红黄线 (Red Lines)
绝不能触发的操作边界，例如“严禁以注释跳过测试对拍”、“禁止跨模块重构未关联逻辑”等。
