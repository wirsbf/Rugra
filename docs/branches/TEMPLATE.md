# 分支状态与工作纪要模板 (Branch Strategy)

当为了避免主线(`master`/`main`)不稳定而拉取关键的隔离分支进行深耕时，在此目录登记此分支的状态，便于所有参与者追踪与排查。

## 命名指引
`[branch-name].md` 

---

## 文档标准

### 1. 拉取分支之目的 (Motivation)
是什么原因促成了此支线开发？（例如大幅度的模型更替、对齐验证攻关或是更换底层分析引擎等）

### 2. 里程碑进展表 (Milestone Checklist)
需要哪些任务被核对完毕：
- [ ] 任务 1
- [ ] 任务 2
- [x] 成功的前置探索

### 3. 当前堵点与挑战 (Blockers)
为何此时还未能回归到主线稳定版？遇到哪些编译或者语义偏差？

### 4. PR 合并退出基准 (Exit Criteria)
罗列所有在发起 Merge 请求前必须要跨越的测试用例、对齐指标与覆盖模块，否则决不可进入主干污染其它人的工作环境。
