# 分级实验跑分记录模板 (Experiments Protocol)

此文件夹记录每一次在核心解码引擎、性能或一致性对拍时采集的数据样本与验证结论。用于支撑后续架构决策或方法论撰写。

## 命名约定
- 日常跑分直接追加到仓库级的 `docs/experiments.md`（按时间倒序）。
- 对于大型验证项目，请命名：`exp_YYYY-MM-DD_<topic>.md`

---

## 模板内容标准

### 1. 实验目标与环境配置 (Setup)
- **编译配置**: (Release 还是 Debug 模式, 是否启用了特定的实验性 feature)
- **对照组**: Ghidra 的哪个版号，或上一次哪个 Commit。
- **数据集**: 使用了哪些测试二进制文件（如 libc 特定函数的 obj）。

### 2. 关键干预变量 (Changes)
引入了哪些修改来进行测试跑分的？（例如替换了某类指令转换表或停用了某个优化 Pass）。

### 3. 数据与观测 (Results & Profiling)
- **准确性对拍比例**: CFG / AST / P-Code 命中率，错误偏离特征。
- **资源损耗/编译消耗**: 跑测耗时。

### 4. 实验结论 (Conclusion)
