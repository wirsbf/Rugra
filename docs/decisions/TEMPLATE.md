# 架构决策记录模板 (Architecture Decision Record)

此文件夹存放所有影响项目脉络的分叉决策，帮助后人理解“当时为何这么选”。

## 约定文件命名
`NNNN_<title>.md` (其中 NNNN 代表自增序列号，例如 `0001_use_iced_x86.md`)

---

## 报告模板结构要求

### 1. 决策背景 (Context/Problem)
为何需要这项决策？存在什么迫切需要解决的鸿沟或问题。

### 2. 候选方案比对 (Considered Options)
- **方案 A**: 描述及其优势、劣势。
- **方案 B**: 描述及其优势、劣势。

### 3. 最终决策方案 (Decision Outcome)
我们选定了哪一个？以及核心出发点（例如是因为能更好地 1:1 对齐 Ghidra 的输出树，还是因为借用 Rust 的强类型特长）。

### 4. 长远影响分析 (Consequences)
决策带来哪些好处以及引入哪些潜在的妥协与技术债。
